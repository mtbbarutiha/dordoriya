# ربات چت ناشناس (مشابه ملوگپ) — مرحله ۱

اسکلت ربات تلگرام فارسی با منوی اصلی، ثبت کاربر و پشتیبانی اولیه از لینک دعوت.

## پیش‌نیاز

- Node.js 20+
- توکن ربات از [@BotFather](https://t.me/BotFather)

## راه‌اندازی

```bash
cd melogap-bot
cp .env.example .env
# BOT_TOKEN را در .env قرار بده
npm install
npx prisma migrate dev --name init
npm run dev
```

## منوی فعلی

| دکمه | وضعیت |
|------|--------|
| بزن بریم ناشناس | تونل شب (مچینگ به‌زودی) |
| نزدیکای شهر | رادار شهری — به‌زودی |
| فیلتر هوشمند | به‌زودی |
| چطور کار می‌کنه؟ | فعال |
| هویت من | فعال |
| کیف سکه | نمایش موجودی |
| دعوت کن، سکه بگیر | لینک دعوت فعال |
| صندوق ناشناس من | به‌زودی |

## لینک دعوت

`https://t.me/<BOT_USERNAME>?start=ref_<CODE>`

اگر کاربر جدید با این لینک `/start` بزند، `referredById` ثبت می‌شود (بدون پاداش سکه در این مرحله).
