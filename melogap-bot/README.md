# ربات چت ناشناس دودوریا — شبیه ملوگپ

Node.js + grammY + Prisma/SQLite

## قابلیت‌ها

- تونل شب: صف مچ ناشناس + رله پیام + `/end`
- نزدیکای شهر: درخواست لوکیشن، فاصله تقریبی، پیشنهاد چت
- فیلتر هوشمند: انتخاب جنسیت و ورود به صف
- کیف سکه: پکیج‌های تومانی + فاکتور دمو + «پرداخت کردم»
- صندوق ناشناس: لینک `anon_CODE`
- دعوت: لینک `ref_CODE` با پاداش سکه
- هویت من: پروفایل + تنظیم جنسیت

## اجرا

```bash
cd melogap-bot
cp .env.example .env   # BOT_TOKEN
npx prisma migrate dev
npm run dev
```

## نکته درگاه

لینک پرداخت فعلاً دمو است (`pay.dordoriya.app`). برای پروداکشن به زرین‌پال / مشابه وصل شود.
